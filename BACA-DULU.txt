TAIDEN INTERPRETER - PROYEK LENGKAP (build lewat GitHub)

CARA MEMBUAT TAIDEN-Setup.exe (lewat GitHub, tanpa instal apa pun di laptop Anda)
1. Buat repo baru di GitHub, lalu upload SEMUA isi folder ini (termasuk folder .github).
   Pastikan build.ps1, TAIDEN.iss, folder app dan folder .github ada di tingkat paling atas repo.
2. Buka tab Actions -> "Build TAIDEN Installer" -> Run workflow -> isi versi (mis. v1.0.0).
   Jika tab Actions kosong, buka Settings -> Actions -> General -> pilih "Allow all actions".
3. Tunggu 30-60 menit. Hasil: tab Releases -> TAIDEN-Setup.exe (sekitar 1-2 GB).
   Tiap build butuh nomor versi baru.

CARA MEMBUAT SECARA LOKAL (alternatif): pasang Inno Setup 6, klik dua kali BUILD.bat.

CARA PAKAI DI LAPTOP LAIN
- Salin TAIDEN-Setup.exe, klik dua kali, Next sampai selesai. Tidak perlu internet, Python, atau instal lain.
- Buka lewat ikon "TAIDEN Interpreter": server jalan DI LATAR BELAKANG (tanpa jendela hitam) dan browser otomatis membuka
  http://localhost:8000/console. Menutup tab browser tidak menghentikan server; jika server crash, ia menyala ulang sendiri.
  Hentikan lewat Start Menu -> TAIDEN -> "Hentikan TAIDEN" (atau Console -> System -> Hentikan server).
  Mode jendela/debug: Start Menu -> "TAIDEN (tampilkan jendela)". Log: "Log TAIDEN" (app\taiden.log).
  Opsional saat install: centang "Jalankan otomatis saat Windows login".
- Settings -> Output Soundcard per Channel: pilih USB codec & nomor Output tiap channel, lalu Simpan.
  (Nomor device tiap laptop berbeda, jadi atur sekali di laptop baru.)
- Pendengar scan QR di Participants. Saat Windows Firewall bertanya, pilih Izinkan (Private network).
- Ganti mode/bahasa/kunci Gemini: Start Menu -> TAIDEN -> "Pengaturan AI (settings.env)".

FITUR
- FLOOR: suara pembicara asli. Settings -> Floor Input -> pilih sumber (Mikrofon/Line-in, Soundcard+nomor Input,
  atau Audio komputer/tab). Nyalakan dengan tombol FLOOR di Home. Pendengar pilih saluran "Floor".
- LIVE CAPTION: teks ucapan tampil di HP pendengar (Floor, penerjemah manusia, dan mode AI).
- BOOTH & AUTO RELAY: Settings -> Booth & Auto Relay. Tiap booth = pasangan sumber -> tujuan, mode Auto (AI relay) atau
  Manual (interpreter manusia). Contoh bawaan: Booth 1 Floor(English)->Indonesia, Booth 2 ->Arab, Booth 3 ->Vietnam.
  Tambah/ubah/hapus booth kapan saja lalu Simpan. Bahasa tersedia: ENG IND CHI ARA JPN VIE KOR THA MAL FRA SPA GER RUS HIN.
  Bahasa pembicara Floor dipilih di Settings -> Floor Input. Bila interpreter manusia bicara (PTT) di channel booth Auto,
  relay AI mengalah 4 detik, jadi AI berfungsi sebagai cadangan otomatis.
- MONITOR INTERPRETER (suara Floor yang didengar penerjemah):
  a) Di komputer ini: Settings -> Monitor Interpreter -> pilih sumber (Floor/channel) dan Output headphone. Tersimpan per browser.
  b) Lewat soundcard/USB codec: Settings -> Booth & Auto Relay -> baris "Headphone booth" -> pilih device + nomor Output.
     Centang "Aktifkan soundcard" di kartu Output Soundcard.
  Bila Floor Input = Soundcard/mixer, Floor terdengar interpreter walau tombol FLOOR OFF (pendengar tidak ikut dengar).
  Sumber Mikrofon/Audio komputer butuh FLOOR ON.
- KONSOL PER BOOTH: buka /console?booth=1 (atau pilih di Settings). Channel terkunci ke booth itu dan sumber booth langsung
  terdengar. Dari komputer lain, mikrofon browser butuh HTTPS (taruh cert.pem + key.pem di folder app).
- Mode offline: Indonesia <-> English selalu ada; Arab dan Vietnam ikut terpasang saat build (ExtraLangs di build.ps1, +~100 MB/bahasa,
  dilewati bila paket Argos-nya tidak tersedia). Suara (TTS) offline memakai suara Windows; bila suara bahasa itu belum terpasang,
  suara dibacakan browser pendengar. Mandarin/Jepang dst. paling baik dengan mode Gemini (settings.env).

Catatan: update aplikasi cukup build ulang & jalankan installer baru; config.json dan settings.env tidak ditimpa.
